# Deloitte Australia - Data Analytics Job Simulation

This repository contains my work from the **Deloitte Australia Data Analytics Virtual Experience Program**.

The simulation focuses on solving business problems for a fictional manufacturing company, **Daikibo Industrials**, using data analysis, visualization, and Excel-based classification.

## 📌 Project Overview

The program consists of two practical tasks:

- **Task 01: Data Analysis** — Analyzed machine downtime across factories and machine types using Tableau.
- **Task 02: Forensic Technology** — Classified pay equality scores using Excel formulas to identify fairness and potential discrimination.

## 🛠️ Tools & Technologies

- **Tableau** — Interactive dashboards and data visualization
- **Microsoft Excel** — Data classification, nested IF formulas, and logical conditions
- **Data Analysis** — Identifying patterns, comparing metrics, and generating business insights

## 📊 Task 01 — Data Analysis (Tableau)

### Objective

Analyze machine telemetry data to identify which factory experienced the most downtime and which machine types contributed most to the problem.

### Work Performed

- Analyzed machine health telemetry data from four factory locations.
- Created a calculated field to estimate machine downtime from unhealthy status records.
- Built bar charts to compare downtime by factory and machine type.
- Developed an interactive Tableau dashboard with filter actions to explore machine downtime at individual factories.

### Key Learnings

- Creating calculated fields in Tableau.
- Building interactive dashboards and visualizations.
- Identifying operational issues through data analysis.
- Presenting insights to support data-driven decision-making.

## 🌐 Task 02 — Forensic Technology (Excel)

### Objective

Investigate pay equality scores across job roles and factories and classify the scores according to their deviation from zero.

### Work Performed

- Analyzed pay equality scores for different job roles and factory locations.
- Applied nested IF formulas and logical conditions in Excel.
- Classified job roles into three categories:
  - **Fair**
  - **Unfair**
  - **Highly Discriminative**
- Used formula-based classification to make the results update automatically when the underlying scores change.

### Key Learnings

- Applying nested IF and OR functions in Excel.
- Implementing rule-based data classification.
- Understanding boundary conditions and logical operators.
- Organizing analytical results for easier interpretation.
